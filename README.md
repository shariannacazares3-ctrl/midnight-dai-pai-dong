# 午夜大排檔 · Midnight Dai Pai Dong

A cozy late-night street food stall game set in 1980s Hong Kong. 🌧️🏮🐈

Run a little stall on a rainy neon street. Make milk tea, egg waffles and curry fish balls for eight kind regulars whose stories unfold night by night. Nobody gets angry and you can't fail. Just rain, lofi radio and a sleepy cat.

- Plays on phone (tap) and desktop (click / keyboard)
- Everything is in one `index.html`: pixel art drawn in code, music and sound made with the Web Audio API
- Progress is saved in your browser (localStorage)
- Sound is off by default. Turn it on from the title screen, the 🔇 button, or by tapping the radio
- Respects `prefers-reduced-motion`; you can also toggle "Calm motion" in ⚙️ Settings

To play, open `index.html` in a browser, or host it on GitHub Pages.
